## 🤖 文档分析专家

本仓库提供了一个专业的 **[高级文件内容分析专家](./高级文件内容分析专家.md)** 系统，用于精准分析和解读这些复杂的规则文档。

### 核心能力

该专家系统具备以下核心能力：

1. **语义级精准检索**: 准确定位规则条款，区分相似表述
2. **逻辑冲突侦测**: 发现文档内部或文档之间的矛盾
3. **证据链闭环**: 确保每个结论都有可追溯的文档引用
4. **多维交叉验证**: 对比不同版本文档，识别版本差异
5. **结构化数据重组**: 将散落信息整理为表格、时间轴等

### 使用场景

- ✅ 查询具体规则条款（如尺寸限制、功率要求）
- ✅ 对比不同版本规则的变化
- ✅ 发现规则冲突或歧义
- ✅ 构建完整的证据链用于答辩或申诉
- ✅ 生成规则摘要和对比表格

### 引用规范

所有分析结果都遵循严格的引用格式：

```
【文件名称 | 页码 P.xx | 章节 x.x】
```

示例：
```
【RoboMaster 2026 比赛规则手册 V1.1.0 | P.15 | 章节 3.2.1】
> "所有参赛机器人的底盘功率不得超过120W"
```

## ⚠️ 重要提示

1. **以文档为准**: 所有分析严格基于提供的PDF文档，不引入外部知识
2. **版本优先级**: 当多个版本存在冲突时，优先采用版本号更高或日期更新的文档
3. **精准引用**: 每个结论都附带完整的文档引用，确保可追溯性
4. **中立客观**: 不添加主观判断，只陈述文档中的事实

## 🔍 常见问题

### Q: 如何查询特定规则？
A: 使用文档分析专家，提供具体问题，系统会检索相关条款并提供精准引用。

### Q: 不同文档有冲突怎么办？
A: 专家系统会列出所有冲突表述，并基于版本号和日期提供效力分析建议。

### Q: 文档中没有的内容会回答吗？
A: 不会。系统严格遵循"知识边界协议"，对于文档中未提及的内容会明确告知。

### Q: 如何查询电池安全相关信息（如盐水比例）？
A: 使用文档分析专家系统，提问"电池盐水比例"等具体问题。系统会从《RoboMaster电池安全规范.pdf》中检索相关条款，并按照标准格式提供引用：【文件名 | 页码 | 章节】。注意：使用时需要能够访问PDF内容（例如通过OCR或文本提取工具）。
